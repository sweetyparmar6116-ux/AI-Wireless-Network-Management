About this prototype

This project implements a focused part of the research paper's closed-loop AI/ML wireless network management concept. The prototype uses Q-Learning to dynamically adjust simulated wireless resource allocation based on network telemetry.

Prototype scope: Dynamic Wireless Resource Allocation AI Controller: Q-Learning

Q-Learning • 5,000 training episodes • 3 actions

Simulation only — not connected to real wireless hardware.
